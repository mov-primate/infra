# Research: Infraestructura MovPrimate

## Decisiones clave

1. Docker Compose como baseline local reproducible.
2. MongoDB y Mongo Express incluidos.
3. Variables por entorno en archivos versionables sin secretos.
4. Estructura preparada para despliegue AWS.

## Resultado

Entorno local consistente para todos los repos de dominio.

## Reglas globales incorporadas

- Configuración para 4 roles y políticas de autorización.
- Configuración para cupo por clase y ventana de cancelación.
- Configuración para correos de confirmación y reenvío.
- Observabilidad para asistencia y agregados de panel superadmin.
