# Quickstart: Infraestructura MovPrimate

1. Copiar .env.example a .env local.
2. Ejecutar docker compose up -d.
3. Verificar salud de app, bff, api, agenda, alumnos, notificaciones y mongo.
4. Validar acceso a Mongo Express.
5. Validar variables de política: cupo máximo 4 y cancelación 60 minutos.
6. Validar conectividad con proveedor SMTP/servicio de correo.
